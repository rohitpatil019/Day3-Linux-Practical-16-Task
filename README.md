📝 6. Practical Tasks

This assignment contains practical Linux tasks completed during training.

Task 1: Linux File and Directory Management

- Create and manage files and directories.
- Use commands such as "mkdir", "cd", "ls", "cp", "mv", and "rm".

Task 2: File Creation and Text Processing

- Create text files using "touch" and "nano".
- Display file contents using "cat" and "head".
- Extract specific content from files.

Task 3: File Redirection

- Redirect command output into files.
- Use ">", ">>", and pipes for data processing.

Task 4: File Permissions

- Understand read, write, and execute permissions.
- Practice "chmod" with numeric and symbolic permissions.

Task 5: User and Group Management

- Create and manage users.
- Create groups and assign users to groups.
- Practice basic account administration.

Task 6: File Ownership

- Understand file ownership.
- Practice "chown" and "chgrp".

Task 7: Text Processing Commands

- Use "head", "tail", "wc", "cut", and "awk".
- Extract and process file information.

Task 8: File Searching

- Search for files and directories.
- Practice "find" and related commands.

Task 9: Process Management

- View running processes.
- Understand process IDs.
- Practice basic process management commands.

Task 10: Service Management

- Check service status.
- Start and stop services.
- Practice basic service troubleshooting.

Task 11: System Information

- Check hostname and system details.
- View CPU, memory, and disk information.

Task 12: Networking Commands

- Check IP addresses and network interfaces.
- Practice "ping", "curl", and route-related commands.

Task 13: File and Directory Permissions

- Practice permission changes using "chmod".
- Understand access control for users and groups.

Task 14: Apache Web Server

- Understand Apache/httpd service operations.
- Check service status and troubleshoot basic issues.

Task 15: Linux Troubleshooting

- Identify common command errors.
- Understand basic permission and file path issues.
- Practice troubleshooting using Linux commands.

Task 16: File Output and Documentation

- Save command outputs into files.
- Verify generated files.
- Document practical work using screenshots.
